🚀 CÁCH DEPLOY:

OPTION 1: Vercel Dashboard (Đơn giản nhất - Khuyên dùng)
  
  Bước 1: Push code lên Git
    git add .
    git commit -m "Ready for Vercel deployment"
    git push origin main

  Bước 2: Deploy trên Vercel
    1. Vào https://vercel.com/new
    2. Đăng nhập bằng GitHub/GitLab
    3. Import repository của bạn
    4. Click "Deploy"
    5. Đợi 2-3 phút → Xong!

  Bước 3: Nhận URL
    https://your-app.vercel.app


OPTION 2: Vercel CLI (Nhanh hơn)
  
  # Cài đặt
  npm i -g vercel

  # Deploy
  cd /path/to/Crawl_MCP
  vercel login
  vercel --prod

  # Hoặc dùng script tự động
  ./QUICK_DEPLOY.sh
